# John Mayoka (MJ) — Portfolio

Personal portfolio website for **John Mayoka (MJ)** — Full-Stack Developer · Software Engineer · AI Engineer · Founder of Mayoka Inc.

> Live: [mayoka.dev](https://mayoka.dev)

---

## Tech Stack

- **React + TypeScript** — frontend framework
- **Three.js / WebGL** — 3D interactive character
- **GSAP** — animations and scroll effects
- **Vite** — build tool

---

## Getting Started

```bash
git clone https://github.com/mayoka0/portfolio-website.git
cd portfolio-website
npm install
npm run dev
```
